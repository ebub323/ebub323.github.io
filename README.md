# techboy.dev

Ebube Eze's portfolio homepage. Next.js static export, deployed to GitHub Pages on every push to `main`
and served at https://techboy.dev.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # writes ./out
```

Project subdomains live in their own repos: [applyr](https://github.com/ebub323/applyr),
[creditbridge](https://github.com/ebub323/creditbridge), [shiftstack](https://github.com/ebub323/shiftstack).
